# DeepL Page Translator (DeepL ページ翻訳拡張機能)

DeepL API を使用して、閲覧中の Web ページ全体をサイレントかつ瞬時に翻訳・置換する Chrome 拡張機能（Manifest V3 対応）です。

テキスト選択ポップアップや右クリックメニュー、画面上の進行状況バーなどの邪魔な UI 要素を一切排除し、**「ページ全体を静かに翻訳する」**機能に特化しています。

---

## 🌟 主な機能

1. **サイレント一括ページ翻訳**
   - ポップアップから言語を選択し「このページを翻訳」をクリックするだけで、レイアウトを崩さずにページ内の英語テキストなどを指定した言語へサイレントに一括置換します。
2. **瞬時の原文復元（元に戻す）**
   - 翻訳されたページは、ポップアップから「元に戻す」をクリックすると、リロードなしで瞬時に元の表示（原文）に復元されます。
3. **英語サイトの自動翻訳（オートトランスレート）**
   - 設定から有効化することで、英語の Web サイト（Wikipedia や海外ドキュメントなど）を開いた際に、自動的に言語を検知してバックグラウンドで翻訳を実行します（デフォルト：オフ）。
4. **安心のセキュリティ設計**
   - Web サイト側と通信を切り離した安全な環境（Isolated World）で動作し、各サイト独自のスクリプトやスタイルに一切干渉しません。

---

## 🛠️ インストール方法

1. **ダウンロードしたフォルダを指定**します。
2. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して移動します。
3. 画面右上の「**デベロッパーモード**」のトグルスイッチを **オン** にします。
4. 画面左上の「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
5. 上記の `deepl_translator_extension` フォルダを選択して読み込みます。
6. 拡張機能一覧に「**DeepL Page Translator**」が表示され、ツールバーにアイコンが追加されれば完了です。

---

## 🚀 使い方と設定手順

### 1. DeepL API キーの設定（初回のみ）
本拡張機能の動作には、DeepL 翻訳用の API キーが必要です。
1. ツールバーの拡張機能アイコン（DeepL ロゴ）をクリックします。
2. ポップアップ上部右側の **歯車アイコン（設定）** をクリックして設定画面を開きます。
3. お手持ちの **DeepL API キー**（`df847...` 等）を入力します。
   - ※ API キーは [DeepL API 登録ページ](https://www.deepl.com/pro-api) から無料プラン（Free）または有料プラン（Pro）に登録することで取得できます。
4. API プランに合わせて 「**Developer (Free)**」 または 「**Pro**」 のいずれかを選択します。
5. 「**保存**」をクリックしてダッシュボードに戻ります。

### 2. ページの手動翻訳
1. 翻訳したい英語などの海外サイト（例: [英語版 Wikipedia](https://en.wikipedia.org/)）を開きます。
2. 拡張機能アイコンをクリックし、「**翻訳先言語**」を選択します（デフォルトは日本語）。
3. 「**このページを翻訳**」をクリックします。
4. ポップアップが自動的に閉じ、バックグラウンドで一括翻訳が実行され、数秒でページ内のテキストが置換されます。

### 3. 原文に戻す方法
1. 翻訳済みのページで拡張機能アイコンをクリックします。
2. 有効化されている「**元に戻す**」ボタンをクリックします。
3. ページ内の日本語テキストが、瞬時に元の英語表示に戻ります。

### 4. 英語サイトの自動翻訳（オートトランスレート）の有効化
1. 拡張機能ポップアップの **設定（歯車アイコン）** を開きます。
2. 「**英語のサイトを自動で翻訳する**」のチェックをオンにします。
3. 「**保存**」をクリックします。
4. 以後、英語の Web ページにアクセスすると、ポップアップを操作せずともバックグラウンドで自動的に翻訳が開始されます。
   - ※ ページ遷移のたびに自動で API の文字数が消費されますので、無料プラン枠（毎月50万文字）などの消費量にご注意ください。

## 📂 ファイル構成

```text
deepl_translator_extension/
├── manifest.json   # 拡張機能の設定メタデータ (Manifest V3)
├── background.js   # APIリクエストを仲介するバックグラウンドスクリプト
├── content.js      # ウェブページ内のテキストを解析・置換するスクリプト
├── popup.html      # ツールバーポップアップのレイアウト
├── popup.css       # ポップアップのデザインスタイル
├── popup.js        # ポップアップの動作制御ロジック
├── README.md       # この取扱説明書（日本語）
└── icons/          # 拡張機能のアイコン画像アセット (16, 32, 48, 128px)
```
